# Aqar Elite — AI Coding Agent Prompt Pack

حزمة Prompts لتنفيذ اختبار Full-Stack الخاص بنظام «عقار اليت» اعتماداً على مستند
`RA-HR-2026-1110` المكوّن من 8 صفحات.

## طريقة الاستخدام
1. افتح مستودع المشروع في AI Coding Agent.
2. اقرأ `00_MASTER_ORCHESTRATOR.md` أولاً وأرسله للوكيل كتعليمات دائمة.
3. نفّذ الملفات بالترتيب من `01` إلى `08`. لا ترسل كل البرومبتات دفعة واحدة.
4. بعد كل Sprint، أرسل Prompt الاختبار المستقل الموجود في نهاية ملف المرحلة، أو اطلب من الوكيل تشغيله كـ QA Engineer منفصل.
5. لا تنتقل للمرحلة التالية إلا بعد اجتياز بوابة الجودة (Quality Gate) وتوثيق الأدلة.
6. احتفظ بسجل القرارات والاختبارات والقيود في `docs/`.

## قاعدة حاسمة
الاختبار قبل التجميل: لا يبدأ بناء واجهات أو إضافة تحسينات شكلية قبل توثيق قواعد العمل
واختبار المنطق الحرج في طبقة مستقلة. لا يُسمح باعتبار المرحلة منتهية لمجرد أن التطبيق
يعمل أو أن TypeScript لا يعرض أخطاء.

## ملاحظة الإصدارات
لا تضع أرقام إصدارات قديمة أو تخمينية داخل البرومبتات. على الوكيل التحقق من أحدث إصدار
Stable متوافق وقت التنفيذ من المصادر الرسمية وبيانات npm، وتسجيل الإصدارات الدقيقة
في `package.json` وملف القفل. لا تستخدم prerelease أو canary إلا بموافقة صريحة موثقة.
